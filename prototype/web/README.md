# 멈칫 클릭 시안

`index.html` 한 파일. 브라우저로 열면 끝(외부 파일·네트워크 없음). 데이터는 메모리에만 있고 새로고침하면 처음으로 돌아가요.

## 상태 바로 열기 (URL 해시)
`index.html#card` 처럼 붙여요. 화면 목록:
`onboarding`(약속 켜기) · `chat`(단톡방 새 주소) · `judging`(판정 중) · `card`(약속 카드) · `charge`(충전 화면 목업) · `cooldown`(30초 쿨다운) · `cooldown-done`(카운트 끝) · `trusted-preview`(신뢰인 알림 미리 보기) · `record`(나의 기록) · `game-pay`(정상 게임 결제, 개입 없음) · `game-pay-false-positive`(정상 게임으로 표시한 뒤) · `settings-off`(끄기 신청, 24시간 뒤 적용 안내)

## 옵션
- `?speed=10` 타이머 10배속 (화면 오른쪽 위 버튼으로도 켤 수 있음)
- `?level=notify|pause|block` 개입 강도 (알려만 주기 / 멈칫하기(기본) / 충전 화면 막기)

## 캡처
`.venv/bin/python prototype/capture.py` (저장소 루트에서)
12개 상태를 412×915 @2x로 `docs/week11/prototype/<해시>.png`에 저장하고 동작을 단언해요. 하나라도 실패하면 종료 코드 1.

## 참고
도박·충전 화면은 CSS로 그린 일반 목업이에요(실제 사이트명·로고·캡처 없음). 판정 근거 키워드는 1차 모델의 기여도 상위 30개 글자 조각에서 고른 값이에요(카지노·슬롯·이벤트·bet 은 상위 30개 안에 있고, 가입·로그인은 일반 단어라 뺐어요. `EVIDENCE` 상수).

## 강도별 규칙
- 카드: 알려만 주기 = [계속 보기] 즉시 / 멈칫하기·충전 화면 막기 = 60초 뒤(막기는 쿨다운에서만 [계속]이 없어요)
- 쿨다운: 알려만 주기 = [계속] 즉시 / 멈칫하기 = 30초 뒤 / 충전 화면 막기 = [계속] 없음
- 쿨다운 남은 시간은 신뢰인 미리보기를 열고 닫아도 이어져요(충전 화면에서 새로 들어올 때만 30초부터).

## 시안 기능 ↔ 1차 모델 지원
시안이 보여 주는 동작 중 현재 1차 모델(이진 판정, `docs/week11/metrics.md`)이 실제로 하는 것은 첫 줄뿐이에요.

| 시안 기능 | 1차 모델 |
|---|---|
| 도박 화면 판정 | 지원 (맥에서 도박/아님 이진 판정) |
| 충전 화면 구분 | 미지원 (12주차 4클래스) |
| 게임 결제 인식 | 미지원 (도박이 아니라고 판정할 뿐 게임 결제인지는 몰라요) |
| 유형·금액 추출 | 미지원 (시안의 '카지노형·5만 원'은 예시) |
| 폰 안 실행 | 미지원 (12~14주차) |
