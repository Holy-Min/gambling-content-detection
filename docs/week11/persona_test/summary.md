## 4. 한계

- LLM 페르소나는 실제 사람의 경험·감정을 대신하지 못하며, 같은 모델이 만든 인물들이라 응답이 비슷한 방향으로 모일 수 있다(Argyle et al., 2023). 이번 결과에서도 "잃은 돈 합계"에 대한 의견이 한쪽으로 크게 쏠렸는데, 이것이 실제 경향인지 모델의 공통 지식(문헌의 추격 손실 개념)인지 구분할 수 없다.
- 정지 화면을 보고 답했으므로 실제 카운트다운의 체감, 금요일 밤의 충동 같은 맥락은 재현되지 않는다.
- 판정 근거 칩은 자리값 상태에서 점검했다.
- 따라서 이 결과는 실제 테스트에서 물을 질문과 바꿔 볼 시안을 고르는 데만 썼고, 지표 7~9의 결과로 주장하지 않는다.
