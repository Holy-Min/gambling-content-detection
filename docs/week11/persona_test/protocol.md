# 진행 방법

- 페르소나마다 별도 AI 에이전트(Claude Sonnet)를 띄운다. 에이전트끼리는 서로의 답을 보지 않는다.
- 에이전트에게 주는 것: 페르소나 카드(personas.md의 한 줄), 공통 AS-IS 시나리오, 「멈칫」 클릭 시안 화면 캡처(docs/week11/prototype/*.png), 아래 질문지.
- 편향 방지 지시: "앱을 칭찬할 필요가 없다. 실제 그 사람이라면 거절·무관심·짜증도 자연스러운 반응이다. 모르면 모른다고 답한다."
- 1회차: 화면을 순서대로 보며 생각 말하기 + 질문지 답 + 정해진 형식의 선택 기록.
- 2회차: 진행자(김성민)가 1회차 답을 읽고 페르소나별 꼬리 질문 2~3개를 같은 에이전트에 이어서 묻는다.
- 진행자는 모든 답을 검토해 수용/보류/기각과 이유를 summary.md에 남기고, 수용한 것만 시안에 반영한다.

# 1회차 질문지

## 사용자 역할(P1~P5: 경험 청소년 대리·회복자 — 회복자는 "그 시절의 나"로 답하고 지금의 생각을 덧붙임)
1. [약속 켜기] 처음 켤 때 무엇을 고르겠어요? 개입 강도(알려만 주기 / 멈칫하기 / 충전 화면 막기) 중 무엇을, 왜? 신뢰인을 정하겠어요? 약속 문구는 뭐라고 쓰겠어요?
2. [약속 카드] 단톡방 새 주소를 누르자 이 카드가 떴어요. 첫 생각은? [나가기]와 60초 뒤 [계속 보기] 중 무엇을 하겠어요? 판정 근거 표시는 이해되나요?
3. [쿨다운] 상품권 핀을 넣으려는데 30초 카운트가 떴어요. 그 30초 동안 뭘 하겠어요? [나가기] / [신뢰인에게 알리기] / [1336 익명 채팅] / (30초 뒤) [계속] 중 무엇을? 잃은 돈 합계를 본 느낌은 — 멈추게 하나요, 오히려 "복구해야지"를 키우나요?
4. 기다리는 시간은 15초 / 30초 / 60초 중 무엇이 적당해요? 왜?
5. 어느 순간이든 감시당한다고 느껴지는 지점이 있나요? (1 전혀 아님 ~ 5 매우 그렇다)
6. 이 앱을 지우고 싶어지는 순간은? 피해 가는 방법이 떠오르나요?
7. 이 앱을 켜 두겠어요? (켜 두겠다 / 지우겠다 / 모르겠다) 무엇이 바뀌면 답이 달라지나요?
8. [정상 게임 결제] 모바일 게임 결제는 그냥 통과해요. 잘못 잡히면 "정상 게임으로 표시"를 누를 수 있어요. 이 부분에서 걱정되는 점은?

## 상담사 역할(P6·P7)
1. 상담 중인(또는 상담을 망설이는) 청소년에게 이 앱을 권할 수 있나요? 어떤 조건이면?
2. 약속 카드·쿨다운 문구 중 수치심을 주거나 동기강화상담 원칙에 어긋나는 표현은?
3. 잃은 돈 합계 표시의 위험(추격 충동 자극)을 어떻게 보나요? 기본값을 무엇으로 두겠어요?
4. 1336 익명 채팅 연결과 신뢰인 알림의 순서·문구에 대한 의견은?
5. 현장에서 예상되는 오용·부작용(예: 보호자가 강제로 설치)과 막을 방법은?
6. 학교·상담 현장에서 이 앱을 소개한다면 어떤 문장으로 소개하겠어요?

## 신뢰인 역할(P8)
1. 자녀가 당신을 신뢰인으로 지정했어요. 받는 알림은 "충전 시도 · 5만 원 · 카지노형"뿐이에요. 충분한가요? 더 알고 싶은 것은?
2. 알림을 받은 그 순간 무엇을 하겠어요? 자녀에게 뭐라고 말하겠어요?
3. "보호 꺼짐" 한 줄을 받으면 어떻게 하겠어요?
4. 자녀 폰에 부모용 감시 앱을 까는 것과 비교하면 어떤가요?
5. 이 방식이 자녀와의 관계에 도움이 될까요, 해가 될까요?
