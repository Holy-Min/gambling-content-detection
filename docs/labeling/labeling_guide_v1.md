# 라벨링 기준서 v1 (2026-11-18)

상태: **확정(2026-11-18).** 고칠 때는 버전을 올리고 10절에 결정 날짜를 적는다.

## 1. 왜 필요한가

- 1차 모델(11/9)은 사이트 단위 라벨을 그대로 화면 정답으로 썼다. 놓친 화면 30쪽 중 12쪽이 라벨이 틀린 화면이었다(정보 글, 리뷰, 무료 영화, 봇 확인 화면).
- 11/9에 판정 대상을 "불법 도박"에서 **"도박 화면 전반"**으로 넓혔는데(청소년에게는 복권·토토·경마·카지노가 모두 금지), 데이터 라벨은 아직 옛 기준이다.
- 10/28~11/18 판정 때마다 정한 기준이 대화와 메모에만 흩어져 있다.

## 2. 한 줄 원칙

> **이 화면에서 돈을 걸 수 있거나, 돈을 거는 곳으로 들어가게 하는 화면이면 도박이다.**
> 도박을 다루지만 돈을 걸 수 없고 그리로 보내지도 않으면 정상이다.

"돈"에는 현금으로 바꿀 수 있는 포인트·코인이 포함된다. 합법·불법은 가리지 않는다.

## 3. 판정 단위

- 정답은 **화면(쪽) 단위**다. 기본값은 그 사이트의 라벨이고, 화면이 사이트 라벨과 다르면 화면 정답이 이긴다.
- 사이트 라벨은 수집 때 `crawler promote`의 판정으로 정해진다(`seeds/*.csv`).
- 화면 정답은 덮어쓰기 파일로 관리한다(7절). 수집 색인(`index.jsonl`)은 고치지 않는다.

## 4. 라벨 정의

| 라벨 | 뜻 | 학습·평가에서 |
|---|---|---|
| `gambling` 도박 | 돈을 걸 수 있는 서비스의 화면, 또는 그리로 들어가게 하는 화면 | 양성(1) |
| `hard_negative` 헷갈리는 정상 | 도박처럼 보이거나 도박을 다루지만 돈을 걸 수 없는 화면 | 음성(0) |
| `normal` 일반 정상 | 도박과 관계없는 화면 | 음성(0) |
| `embedded_banner` 도박 배너가 실린 일반 사이트 | 본 내용은 정상인데 도박 광고가 붙은 화면 | 학습에 넣지 않고 따로 보고 |
| `legal_gambling` 합법 사행 | 복권·토토·경마·경륜·경정·합법 카지노 사업자의 화면. 판정 대상(도박)이지만 따로 다룬다 | 모델 학습에 넣지 않고 상표 낱말 규칙으로 잡음. 규칙이 잡은 비율을 따로 보고 |
| `exclude` 제외 | 정답을 말할 수 없거나 수집 대상이 아닌 화면 | 학습·평가에서 뺌 |

수집 전용 판정(화면을 데이터셋에 넣지 않음): `community`(링크 수집만), `blocked`(국내 회선 차단), 비움(판정 보류).

## 5. 유형별 판정

### 도박 (`gambling`)

| 유형 | 근거 |
|---|---|
| 카지노·슬롯·스포츠 베팅·파워볼·미니게임 사이트의 첫 화면, 게임 목록, 가입, 로그인, 충전·환전 | 돈을 걸 수 있음 |
| 접속 주소 안내(평생 도메인, "현재 접속 가능한 주소", 가입 코드) | 들어가게 함 |
| 가입·보너스·공식주소 버튼이 있는 브랜드 제휴 랜딩 | 들어가게 함 (11/16) |
| 카지노·슬롯 방송(스트리머가 가입을 홍보) | 들어가게 함 (11/18) |

### 합법 사행 (`legal_gambling`)

| 유형 | 근거 |
|---|---|
| 복권, 스포츠토토, 경마, 경륜, 경정, 합법 카지노 안내 사이트의 발매·게임·가입·첫 화면 | 판정 대상 = 도박 화면 전반 (11/9). 사업자 수가 정해져 있어 모델 대신 상표 낱말 규칙으로 잡는다 (11/18) |
| 같은 사이트의 공지·이벤트·약관 화면 | **제외** (11/18) |

상표 낱말 목록은 판정 엔진의 `src/detector/rules.py`(`LEGAL_BRAND_TERMS`)에 둔다.

### 헷갈리는 정상 (`hard_negative`)

| 유형 | 근거 |
|---|---|
| 게임 캐시·아이템 충전, 상품권·기프트카드, 간편결제 | 충전 화면이지만 돈을 걸지 않음 |
| 룰렛·출석체크·경품 이벤트 | 돌림판 모양이지만 돈을 걸지 않음 |
| 경기 결과·실시간 스코어·e스포츠 일정(도박 광고 없음) | 정보만 제공 |
| 코인 거래소·주식 시세·환율(도박 광고 없음) | 투자 화면 |
| 축구 예측·배당 변동 사이트(바깥 도박 광고 없음) | 돈을 걸 수 없음 (11/18) |
| 카지노 게임 공급사의 회사 소개 사이트 | 돈을 걸 수 없음 (11/18) |
| 일반 사이트의 공식 주소만 싣는 주소 모음 | 주소 안내 모양이지만 도박이 아님 (11/16) |
| 놀이시설 안전 기관("안전놀이터"), 크리스털 브랜드 "바카라" 기사 | 단어만 같음 |
| 무료 카드 게임(돈을 걸지 않는 바카라 등), 복권 번호 통계 | 돈을 걸 수 없음 (11/18) |

### 도박 배너가 실린 일반 사이트 (`embedded_banner`)

| 유형 | 근거 |
|---|---|
| 무료 스포츠 중계, 무료 웹툰·영화 다시보기에 도박 배너가 붙은 것 | 본 내용은 정상, 광고가 도박 (11/16) |
| 베팅 광고가 붙은 스코어·코인 시세 사이트 | 같음 (11/16) |

### 제외 (`exclude`)

| 유형 | 근거 |
|---|---|
| 봇 확인, 접근 거부, 오류, 빈 화면, 주차 도메인 | 볼 내용이 없음 |
| 도박 사이트 안의 약관·정책 글처럼 도박 요소가 전혀 보이지 않는 화면 | 화면만으로 정답을 말할 수 없음 |
| 추천 순위·리뷰·설명 글·도움말·블로그(가입 버튼 없음) | 수집 대상이 아님. 가입 버튼이 있으면 도박 |

### 커뮤니티 (`community`, 화면 저장 안 함)

- 먹튀검증·보증업체 커뮤니티, 도박 배너를 모아 둔 추천 순위 페이지: 링크 수집에만 쓴다.
- 성인 게시판에 도박 배너가 붙은 것: 화면을 데이터셋에 넣지 않으려고 커뮤니티로 둔다(11/17).

## 6. 헷갈릴 때 보는 순서

1. 볼 내용이 있는가? 없으면(봇 확인·오류·빈 화면) **제외**.
2. 이 화면이나 이 사이트에서 돈을 걸 수 있는가? 그러면 **도박**.
3. 돈을 거는 곳으로 가는 버튼(가입·접속 주소·보너스)이 화면의 주된 내용인가? 그러면 **도박**.
4. 본 내용은 정상인데 도박 광고가 붙어 있는가? 그러면 **배너 사이트**.
5. 도박처럼 보이거나 도박 단어가 나오는가? 그러면 **헷갈리는 정상**, 아니면 **일반 정상**.
6. 그래도 정하지 못하면 비워 두고 사유를 적는다. 억지로 넣지 않는다.

## 7. 정답 파일

- 위치: `docs/labeling/labels_v1.csv`
- 칸: `unit`(site·screen), `key`(사이트는 도메인 해시, 화면은 색인 id), `label`, `reason`, `checked_by`, `checked_at`
- 읽는 순서: 화면 줄 → 사이트 줄 → 색인의 원래 라벨. 앞의 것이 이긴다.
- 실제 도박 사이트의 주소는 적지 않고 도메인 해시만 적는다.

## 8. 시험 세트

- **첫 수집일이 2026-11-13 ~ 2026-11-18 인 사이트**를 통째로 시험 세트로 뗀다. 학습에는 한 화면도 넣지 않는다. 시험 세트는 이 범위로 고정하고, 2026-11-19부터 처음 수집하는 사이트는 학습 세트로 간다(11/18 결정).
- 시험 세트 화면은 **전부 사람이 눈으로 확인**해 정답을 적는다. 모델 예측을 보고 고르지 않는다.
- 학습 세트는 규칙으로 고칠 수 있는 것(9절)을 먼저 고치고, 기준선 학습 뒤 모델과 라벨이 크게 어긋나는 화면만 눈으로 확인한다.
- 시험 세트 사이트가 학습 세트 사이트의 미러(같은 화면, 다른 주소)인지 표시해 "주소만 바꾼 사이트"와 "처음 보는 사이트"를 나눠 보고한다.

## 10. 정한 것 (2026-11-18 사용자 결정)

1. **배너 사이트**: 학습의 양성·음성 어디에도 넣지 않는다. "배너 사이트 화면 중 몇 %를 도박으로 잡는가"를 따로 보고하고, 앱이 이 화면에서 멈출지는 그 수치를 보고 정한다.
2. **무료 카드 게임과 복권 번호 통계**: 헷갈리는 정상. 2절 원칙(돈을 걸 수 없음)에 따른다.
3. **시험 세트 기준일**: 2026-11-13. 이날 이후 처음 수집한 사이트는 통째로 시험 세트다. 9~10절 반영 뒤 크기는 판정 엔진의 평가 결과 문서(`metrics_v2.md`)에 적는다. 일반 정상 8곳은 모두 9/30에 수집해 시험 세트에 없다.
4. **시험 세트 고정**: 처음 정한 "기준일 이후 전부"를 2026-11-13 ~ 2026-11-18 로 고친다. 새 사이트가 모두 시험 세트로 가면 학습 데이터가 늘지 않기 때문이다.
5. **합법 사행**: 모델 학습에 넣지 않고 상표 낱말 규칙으로 잡는다. 1차 재학습에서 글자 모델이 합법 사행 화면 119쪽 중 81쪽을 놓쳤고, 합법 사업자는 수가 정해져 있다.
6. **합법 사행 사이트의 공지·이벤트 화면**: 제외.
